#   Заметки по обучению Dev_Ops

##  Темы
* nginx 
    Веб-сервер выступающий в роли шлюза распределяющего в том числе нагрузку между серверами(потом дополнить)
    установка Nginx 
    > apt update && apt install Nginx
    Правилом хорошего тона будет проверить статус сервиса
    > systemctl status Nginx
    кроме того будет правильно проверить доступен ли 80 и 443 пор в фаерволе
    > ufw status
    Если доступ не разрешен требуется разрешить его с помощью команды 
    > ufw allow 80/tcp && ufw allow 443/tcp
    После всего этого можно будет увидеть стартовую страницу Nginx
    
*Может быть полезно
    > mkdir - создание папки
    > ip -br a -Вывод ip в человекочитаемом виде.
